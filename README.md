# ZooMochi 🐾

Prima demo mobile di ZooMochi.

## Funzioni
- Animaletto virtuale con fame, felicità e pulizia
- Monete
- Minigioco evento settimanale
- Classifica demo
- Premio estetico per il 50% migliore
- Armadio accessori
- Salvataggio locale dei progressi

## Prova rapida
Apri `index.html` in un browser.

## Pubblicazione come sito
La demo può essere pubblicata con GitHub Pages dalle impostazioni del repository, usando il branch `main` e la cartella root.

## Prossimi passi
Trasformazione in app Android installabile, grafica originale, più animali, account giocatore, eventi online e classifica reale.
